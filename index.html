소개

AI를 업무에 적용하고, 현업에서 사용할 수 있는 서비스로 만드는 13년차 소프트웨어 엔지니어입니다.

LLM·RAG·MCP·생성형 AI를 활용해 문서 검색, 데이터 분석, 콘텐츠 제작, 리서치 자동화 등 업무에 필요한 기능을 개발하고 있습니다. 기능 검증이나 데모에 그치지 않고, 사용자가 반복해서 사용할 수 있는 서비스로 구현하고 운영하는 데 집중합니다.

AI 모델뿐 아니라 서비스를 운영하기 위한 환경도 직접 다룹니다. 외부 AI 서비스를 사용할 수 없는 폐쇄망에서 H200 GPU 서버 기반의 로컬 LLM 환경을 구축·운영했으며, 모델과 서버 설정을 조정해 응답 속도와 안정성을 개선했습니다. 사내 문서와 업무 데이터를 활용한 RAG 검색과 견적 분석, 시나리오 분석부터 이미지·영상 생성까지 이어지는 제작 기능도 개발해 실제 업무에 적용했습니다.

최근에는 MCP를 활용해 LLM과 기존 데이터·업무 도구를 연결하고, AI가 필요한 정보를 찾고 도구를 실행할 수 있는 Agent 기능을 개발하고 있습니다. 뉴스와 지원사업처럼 반복적으로 정보를 찾고 정리해야 하는 업무에도 AI를 적용해 자동화 범위를 넓혀 왔습니다.

13년 동안 웹·모바일 서비스와 다양한 업무 시스템을 개발하며 DB·API·UI 설계부터 서버 구성, 배포와 운영까지 서비스 전반을 직접 다뤄왔습니다. 이러한 경험을 바탕으로 AI 기능 역시 별도의 기능으로 두기보다 기존 시스템과 데이터, 사용자의 업무 흐름에 연결해 하나의 서비스로 완성하는 것을 중요하게 생각합니다.

새로운 기술을 빠르게 적용하는 것보다 누가 어떤 업무에 사용할 것인지 먼저 파악하고, 필요한 기능을 안정적으로 구현해 실제 사용까지 이어지게 하는 것을 개발의 기준으로 삼고 있습니다.
