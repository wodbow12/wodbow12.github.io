프레임 단위 재생·주석·구간 편집과 ShotGrid 조회·난이도 평가를 한 도구에 구성했습니다. 난이도는 명시적 계산 규칙으로 처리하고, 평가 기록 저장과 최종 필드 반영의 조건을 분리했습니다.

ARCHITECTURE & DECISIONS

01

웹과 데스크톱의 계산 규칙 일치

평가 계산·입력 정규화를 공통 코어로 분리하고 웹·데스크톱 파일 동기화 검사로 결과 차이를 확인했습니다.

02

평가 기록의 기준을 ShotGrid로 통일

ShotGrid에 이력을 누적하고 최신 유효 평가로 집계해, 미평가 상태가 0점으로 반영되지 않게 했습니다.

03

최종 반영을 별도 승인 절차로 설계

완료 여부·권한·대상 필드를 검사하고 승인 후 반영하도록 설계했으며, 실제 서버는 드라이런까지 검증했습니다.

설계 판단과 구현

웹과 데스크톱의 계산 규칙 일치

카메라·오브젝트·장애 요소·작업 방식·길이·추가 요소의 점수 계산을 공통 코어로 분리했습니다. 두 도구가 동일 파일을 사용하도록 배치하고 동기화 검사로 차이를 확인했습니다. 입력 기본값과 오타 정규화도 계산 직전에 적용해 경로에 따른 결과 차이를 방지했습니다.

평가 기록의 기준을 ShotGrid로 통일

ShotGrid에 평가 이력을 누적 저장하고, 화면과 집계에는 샷·평가자별 최신 유효 값을 사용하도록 구성했습니다. 값이 없는 항목을 0점으로 저장하지 않아 미평가 상태와 실제 평가를 구분했습니다. 로컬 캐시는 응답 속도와 연결 실패 대응에 한정했습니다.

최종 반영을 별도 승인 절차로 설계

평가 완료 여부·권한·부서별 대상 필드를 검사하고 사용자 승인 후 반영하도록 구현했습니다. 대상 필드가 없으면 서비스와 UI에서 모두 차단하고, 일괄 갱신 실패 시 개별 재시도와 실패 표시를 제공했습니다.

검증 과정

드라이런에서 부서별 숫자 필드와 평가 완료 조건을 확인했습니다. 미설정 필드와 완료 대상 부재 상태에서는 반영을 차단했습니다. 다이얼로그 생성 직후 반영 버튼이 잠시 활성화되던 결함을 수정하고 다시 검증했습니다. 실제 데이터 반영 시험은 전용 테스트 대상 확보 후 수행하도록 구분했습니다.

구현 결과

정밀 영상 리뷰와 샷 평가를 하나의 데스크톱 도구에 연결했습니다. 계산 규칙 공유, 이력 기반 집계, 권한·완료 조건 검사와 승인 절차를 통해 업무 데이터에 반영할 기준을 구현했습니다.

다음 개선 방향

전용 테스트 샷을 활용한 승인 후 실반영 검증과, 실제 영상 픽셀 기준의 색상·비교 기능 회귀 범위를 확장합니다.
