소개

웹 서비스와 사내 업무 시스템을 개발해 온 13년차 개발자입니다.

현업과 대화하며, 필요한 기능을 함께 찾는 개발자입니다.

요청받은 기능을 만들기 전에 사용자가 어떤 일을 하고, 어디에서 불편을 겪는지 확인합니다. 제조업의 수주·재고 관리부터 VFX 제작 도구까지 여러 분야의 업무를 맡으며, 담당자와 업무 절차와 예외 상황을 정리해 왔습니다. 최근에는 PM·슈퍼바이저와 문서 검색, 견적 검토, 제작 관리에 필요한 기능을 함께 정리하고 실제 사용 의견을 반영했습니다.

직접 만들고, 실제 업무에 쓰일 때까지 챙기는 개발자입니다.

데이터베이스와 API, 화면을 설계하고 개발·배포·운영까지 맡아 왔습니다. 그룹웨어와 제조 업무 시스템을 운영했고, VFX 제작 현장에서는 파일 업로드·검수·승인 과정을 ShotGrid와 연결해 반복 작업을 줄였습니다. Maya·Nuke 제작 도구와 영상 리뷰 도구도 개발하며, 담당자가 결과를 확인하고 다음 작업으로 이어갈 수 있도록 업무 흐름에 맞춰 구현했습니다.

AI를 익히고, 업무에 맞게 적용하는 개발자입니다.

AI와 MCP를 개발과 업무 자동화에 적극적으로 활용합니다. 폐쇄망에서 작업한 경험을 바탕으로 사내 GPU에 로컬 LLM을 적용·운영하고, 응답 지연과 오류를 개선했습니다. 사내 문서와 ShotGrid 데이터를 활용한 검색·견적 분석 도구, 시나리오 분석에서 이미지·영상 생성으로 이어지는 제작 기능을 개발했으며, 뉴스·지원사업 리서치 자동화도 운영했습니다.
