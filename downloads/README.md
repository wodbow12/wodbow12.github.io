# 이력서 수정

- resume.html: 본문 문구와 경력. resume-page 구역 4개가 인쇄 페이지 4장입니다.
- resume.css: 글자 크기, 간격, A4 인쇄 서식. @media print가 인쇄용 설정입니다.
- lee-dongwon-resume.pdf: 현재 HTML을 인쇄한 배포본입니다.

resume.html을 브라우저로 열고 ‘인쇄 / PDF 저장’을 누릅니다. 용지는 A4, 배율은 100%, 여백은 없음, 머리글·바닥글은 끄고 저장합니다. HTML 변경 후에는 PDF도 다시 저장해야 사이트의 이력서 다운로드에 반영됩니다. 페이지별 내용이 늘어나면 인쇄 미리보기에서 넘침을 확인하세요.

예전 resume-content.md는 이전 요약본이므로 현재 이력서 수정에는 resume.html을 사용합니다.
